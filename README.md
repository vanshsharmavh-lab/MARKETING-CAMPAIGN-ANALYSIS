# MARKETING-CAMPAIGN-ANALYSIS
# Marketing Campaign Performance Analysis

## Project Overview

This project analyzes digital marketing campaign data to understand campaign performance, customer engagement, revenue generation, and profitability.

The goal is to identify which platforms, campaign objectives, and marketing strategies provide better business results.

## Objectives

- Analyze marketing campaign performance
- Measure CTR, conversion rate, CPC, and ROAS
- Compare platform performance
- Identify profitable campaigns
- Generate business insights from data

## Dataset Features

The dataset contains information about:

- Campaign details
- Platform and ad placement
- Target audience
- Creative details
- Impressions and clicks
- Conversions
- Ad spend
- Revenue
- Profit
- Marketing KPIs

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook / VS Code

## Project Workflow

### 1. Data Loading
- Imported marketing campaign dataset
- Checked dataset structure

### 2. Data Cleaning
- Removed duplicate records
- Handled missing values
- Prepared data for analysis

### 3. Performance Analysis
Analyzed:
- Total impressions
- Clicks
- Conversions
- Revenue
- Profit
- CTR
- ROAS

### 4. Campaign Comparison

Compared:
- Performance by platform
- Performance by campaign objective

### 5. Visualization

Created charts to understand:
- Revenue by platform
- Profit by campaign objective
- CTR vs Conversion relationship

## Key Metrics

- CTR (Click Through Rate)
- CPC (Cost Per Click)
- Conversion Rate
- CPA (Cost Per Acquisition)
- ROAS (Return on Ad Spend)
- Profit

## Business Insights

- Identified high-performing marketing platforms
- Found profitable campaign objectives
- Evaluated return from advertising spend
- Helped in making data-driven marketing decisions
